5. CARACTERÍSTICAS Y CONSIDERACIONES
----------------------------------------------------------------------------------------------------

CBLOF (Cluster-Based Local Outlier Factor):
  Ventajas:
    ✓ Utiliza clustering para contexto local
    ✓ Bueno para detectar anomalías locales dentro de clusters
    ✓ Considera la densidad y estructura de los datos
    ✓ Puede identificar diferentes tipos de anomalías
  Desventajas:
    ✗ Requiere especificar número de clusters
    ✗ Más sensible a la elección de parámetros
    ✗ Puede ser más lento en grandes datasets
    ✗ Complejidad computacional mayor

Isolation Forest:
  Ventajas:
    ✓ Basado en ensemble de árboles de decisión
    ✓ Rápido y escalable a grandes volúmenes de datos
    ✓ Funciona bien con datos de alta dimensionalidad
    ✓ No requiere clustering previo
  Desventajas:
    ✗ Puede ser sensible al parámetro de contaminación
    ✗ Menos interpretable que métodos basados en distancia
    ✗ Puede tener problemas con distribuciones no uniformes
